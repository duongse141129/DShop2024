# DShop E-Commerce Web Application

A modern full-featured e-commerce web application built with **ASP.NET Core 8** using the **MVC architecture**. This project provides a complete online shopping platform with AI-powered features, real-time communication, secure online payments, inventory management, and an administration dashboard, ...

## ✨ Features

### 🛍️ Customer Features

- User registration & authentication
- Product search and advanced filtering
- Shopping cart
- Wishlist
- Product comparison
- AI Chatbox
- Real-time chat (text & image)
- Product recommendation system
- Coupon & discount system
- Online payment with **MoMo** and **VNPay**
- Order tracking
- Order return & refund
- Product reviews & ratings

### 📰 Blog System

- Blog posts
- Blog subjects 
- Comment system
- Like system

### 👨‍💼 Admin Features

- Dashboard
- Product management
- Category & brand management
- Inventory management
- Shipping management
- Order, Return, Refund management

- Privacy Policy & FAQ Management

## 🚀 Getting Started

### Clone the repository

```bash
git clone 
```

### Configure the database

Update the connection string in `appsettings.json`.

### Apply migrations

```bash
dotnet ef database update
```

### Run the application

```bash
dotnet run
```
